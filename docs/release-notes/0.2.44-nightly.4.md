## New

- **Sidebar on the right**: pick Right under the layout cards in Make it yours, in Settings › Tabs › Sidebar position, or with View › Sidebar on Right. Only the sidebar layout moves. The hidden sidebar peeks in from the right as well.
- **New-tab links can stay in Little UniVerse**: turn on Settings › General › "Open new-tab links inside Little UniVerse" and a link that would open a new tab loads in Little UniVerse itself, so Back takes you back. It's off by default. Thanks, [@narasaka](https://github.com/TheSatyam-Singh/UniVerse-Project-Browser/pull/344).
- **`universe browse`** takes agent-browser's commands and runs them on the UniVerse Project Browser you have open, so an agent that knows agent-browser can use UniVerse Project Browser as it is. It needs "Let the universe command control UniVerse Project Browser" turned on.

## Fixed

- **Expanding Little UniVerse while a link is still loading** no longer leaves the tab stuck on a blank page. Thanks, [@narasaka](https://github.com/TheSatyam-Singh/UniVerse-Project-Browser/pull/551).
- **The traffic lights in the peeked sidebar** respond to clicks and hovers again when the address bar is in the toolbar. Thanks, [@narasaka](https://github.com/TheSatyam-Singh/UniVerse-Project-Browser/pull/771).
- **Tabs moved to another window** (Open in UniVerse Project Browser, Move to Window, a drop on another window) land where "New tabs open at" puts a new tab, and never inside a group. Thanks, [@daberni](https://github.com/TheSatyam-Singh/UniVerse-Project-Browser/pull/730).

## Smaller

- A tab group's last row rounds its corners to match the group box.
- The bundled uBlock Origin is now 1.75.2.
